時間は読み込みから人による確認完了まで。インストールと初期設定は別記する。検出件数は全機密情報に対する再現率ではない。精度を評価する合成入力では、期待マスク範囲と非対象範囲を先に定め、形式別に見逃し・誤検出を記録する。実ログの全秘密を知っているとは仮定しない。

元の作業がインフラ分析結果の提出なら、分析と証拠整理にかかった時間を伏字の時間から分ける。前者が主な負担なら、上の比較を無理に実施せず、[報告の記録型](INFRA_REPORT_TEMPLATE.md)または既存の様式で不足が解消するかを先に確認する。
